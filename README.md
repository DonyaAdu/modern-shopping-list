# 🛒 Shopping List Printer

A cute browser-based shopping list with a little pink printer, heart-shaped bullets, and a smooth paper animation. Make your everyday shopping a little more fun! 🩷

## ✨ Features

- 📝 Add shopping items with a click or the Enter key
- 🖨️ Reveal your list with a smooth printing animation
- 📜 Paper grows with your list so every item fits
- ♡ Click items to mark them as purchased
- 💗 Filled hearts and crossed-out text for completed items
- 🔄 Click again to uncheck an item
- 🗑️ Clear the entire list and start fresh
- 🎀 Pastel pink colors and pixel-style typography
- 📱 Responsive layout for desktop and mobile
- 🌿 Respects your device’s reduced-motion preference
- 💻 Runs directly in the browser

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web Animations API
- Google Fonts — Pixelify Sans

## 🚀 Getting Started

1. Download the repository using **Code → Download ZIP**, or clone it using its GitHub URL.
2. Open the project folder. If you downloaded a ZIP, extract it first.
3. Open **index.html** directly in your browser.

You can also use **VS Code Live Server** while working on the project.

No installation, build step, or backend server needed. Just open and enjoy! ✨

## 🖨️ How It Works

1. Type something you need to buy.
2. Click **Add** or press **Enter** to add it to your list.
3. Keep adding all your shopping essentials.
4. Click **Print** and watch the paper slide out of the pink printer.
5. Click an item when you’ve picked it up — its heart fills in and the text gets crossed out.
6. Added something else? Click **Print** again to show your updated list.
7. Ready for a new shopping trip? Click **Delete List**.

> 🩷 Items appear on the paper after you click **Print**. Printing is an on-screen animation.

## 📜 A Little Room for Everything

From a quick coffee run to a full grocery trip, the paper grows with your list.

- 🧾 Long lists stay above the printer
- 📝 Long item names wrap onto the next line
- ↕️ Scroll the page to see the rest of your list
- ✨ The printing animation adjusts its duration to the paper’s height

## 🌐 Browser Support

Use a current browser that supports the Web Animations API, such as:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

The custom font loads from Google Fonts. If it’s unavailable, the app uses a monospace fallback.

## 🎨 Customization

Make the printer match your own style by editing **style.css**.

You can change:

- 🎀 Colors and backgrounds
- 🔤 Fonts and text sizes
- 💗 Hearts and item styling
- 🖨️ Printer details
- 📜 Paper spacing
- 📱 Responsive layout

To adjust the print animation or shopping list behavior, edit **script.js**.

Button labels, the page title, and input placeholder live in **index.html**.
